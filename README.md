# Dapur Pintar — Generator Resep Masakan AI

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![React](https://img.shields.io/badge/React-18-61dafb?logo=react)](https://react.dev)

Tidak tahu mau masak apa? Masukkan bahan-bahan yang ada di kulkas, AI akan menyarankan resep masakan yang bisa dibuat. Gratis, tanpa login, langsung jadi.

---

## Fitur

- 🤖 **AI Resep Generator** — Input bahan, dapat rekomendasi resep
- 🥘 **Berbagai Masakan** — Resep Indonesia dan internasional
- 📱 **Mobile Friendly** — Optimal di HP
- 🌐 **No Backend** — Sepenuhnya di browser

---

## Quick Start

```bash
git clone https://github.com/alfindigital/dapurpintar.git
cd dapurpintar
npm install
npm run dev
npm run build
```

---

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
